# 50 API

この章群では、REST API を「設計する」「読む」「確かめる」ための考え方を学びます。
[20-09 REST コントローラ](../20-basics/20-09-rest-controller.md) で書き方を学んだ API を、設計の観点から見直します。
目安の期間は **1 週間** です。

!!! abstract "この章群の到達目標"
    - リソースと HTTP メソッドで、分かりやすい API の URI を設計できる
    - 結果ごとのステータスコードとメッセージ ID を決め、エラー応答を統一できる
    - OpenAPI で API 仕様を書き、設計書との差分を確かめられる
    - 認証と認可の違いを説明し、他人のデータが見えてしまう誤りを指摘できる
    - API テストと版の管理で、利用者を壊さずに API を変更できる

## 前提

- [20 基礎](../20-basics/index.md) の 20-09（REST コントローラ）と 20-17（Karate）を終えていること
- sample-app の会員 API（API0001 照会 / API0002 登録）を `curl` で呼べること
