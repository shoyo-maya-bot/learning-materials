# 付録

本文の各章から参照する資料をまとめています。最初から順に読む必要はありません。困ったときに開いてください。

| ページ | 内容 | 使う場面 |
|---|---|---|
| [つまずき集](troubleshooting.md) | よくあるエラーの症状・原因・対処 | 環境構築やビルドでエラーが出たとき |
| [外部参照](references.md) | 公式ドキュメントへのリンク集 | 教材より詳しく調べたいとき |
| [質問のコツ](how-to-ask.md) | 質問に含める情報、テンプレート、15 分ルール | 自分で解決できず、人や AI に聞くとき |

!!! tip "調べる順番"
    1. エラーメッセージをよく読む（最初に出たエラーを探す）
    2. [つまずき集](troubleshooting.md) に同じ症状がないか探す
    3. [外部参照](references.md) の公式ドキュメントで確認する
    4. 15 分たっても進まなければ、[質問のコツ](how-to-ask.md) に沿って聞く
