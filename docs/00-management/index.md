# 00 マネジメント

この節は、案件（プロジェクト）を **進める・まとめる立場の人** に向けたものです。
番号は「00」ですが、教材の **最後に読む** ことを想定しています。

## 誰が読むか

- リーダーやサブリーダーとして、見積もり・計画・進捗報告を担当する人
- 開発メンバーとして、自分の作業が案件全体のどこに位置づくかを知りたい人

新しく参加した開発者は、まず「10 環境構築」から「60 設計品質」までを終えてください。
開発の中身を知っていると、見積もりや品質の数字の意味が分かりやすくなります。

!!! info "道具は手段"

    数字をきれいに見せることが目的にならないよう、常に「何を判断するための数字か」を意識してください。
