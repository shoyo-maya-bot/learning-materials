# 開発者向け教材（Java / Spring Boot）

新しく参加した開発者が、**環境構築 → 基礎 → 実ソースの読解 → API・非同期処理・設計品質 → クラウドとアーキテクチャ → 案件担当になる** の順に学ぶ教材です。
教材のコードは、開発環境のリポジトリ（dev-environment）の `sample-app`（会員 API と注文ファイル取込バッチ）を使います。

| 編 | 内容 | 章 | 目安 |
|---|---|---|---|
| [10 環境構築](10-setup/index.md) | Git・JDK・VS Code・コンテナ・sample-app の実行・Copilot | 6 | 1 週目 |
| [20 基礎](20-basics/index.md) | Java・Gradle・Spring Boot・SQL / MyBatis・テスト・Git の運用 | 18 | 2〜3 週目 |
| [30 実ソース読解](30-reading/index.md) | sample-app を 1 本ずつ読む（演習と解答つき） | 15 | 3〜4 週目 |
| [40 非同期処理](40-async/index.md) | スレッド・キュー・再試行・冪等性 | 2 | 担当に応じて |
| [50 API](50-api/index.md) | REST 設計・エラー応答・OpenAPI・認可・テスト | 7 | 担当に応じて |
| [60 設計品質](60-quality/index.md) | 設計書の書き方・レビュー・品質の測り方・AI の出力を疑う（演習） | 4 | 担当に応じて |
| [70 クラウドとアーキテクチャ](70-cloud/index.md) | 上流工程と非機能要件・設計の基礎・AWS・Azure・資格試験 | 7 | 設計・クラウドの担当者 |
| [80 案件担当になる](80-case-owner/index.md) | 到達度の目安と自己診断、見積・計画・報告、設計の読み方と改善、テスト観点、標準ルールの「なぜ」 | 13 | 1 案件を任される前に |
| [00 マネジメント](00-management/index.md) | 見積もり・進捗・品質・リスク・報告 | 1 | 案件の担当者 |
| [付録](appendix/index.md) | つまずき集・外部参照・質問のコツ | 3 | 必要なときに |

最初に [学習の進め方](guide.md) を読んでください。

!!! note "この教材のサンプルについて"
    sample-app は学習用の架空のシステムです。いくつかの章では、sample-app にあえて残っている改善点（同時登録の扱い、
    バッチの異常系など）を演習の題材にしています。実案件では、同じ観点で実際のソースを読んでください。
