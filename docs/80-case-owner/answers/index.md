# 80 案件担当になる 解答

「80 案件担当になる」の各章末にある「演習」の解答です。

!!! warning "先に自分で解いてください"
    この編の演習の多くは、答えが 1 つに決まりません（見積・計画・報告・改善の提案）。
    解答は「考え方の一例」です。自分の答えと比べて、抜けている観点が無いかを確かめてください。
    できれば、自分の答えを先輩や同僚に見せて、説明してみてください。説明できることが、案件担当の水準です。
