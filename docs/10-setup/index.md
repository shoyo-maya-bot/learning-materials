# 10 環境構築

この節では、自分の PC（Windows 11）に開発環境を作り、サンプルアプリ（sample-app）を動かすところまで進めます。
以降の「20 基礎」「30 実ソース読解」は、この節で作った環境を使って手を動かす前提で書かれています。

## この節を終えると

- Git・JDK・VS Code・コンテナ環境（Rancher Desktop）が入り、コマンドで版を確認できる
- `dev-environment` リポジトリを clone し、DB（PostgreSQL）と S3 エミュレータをコンテナで起動できる
- sample-app をビルドし、会員 API を `curl` で呼び出せる
- 注文ファイル取込バッチ（JOB0001）を起動し、終了コードとログを確認できる
- 単体テスト（`./gradlew test`）と API テスト（`./gradlew karateTest`）を実行できる
- GitHub Copilot を設定し、「AI の出力は下書き」という前提で使い始められる

!!! info "使うソフトはすべて無償"
    この教材の手順は、無償で使えるソフトだけで組み立てています。
    たとえばコンテナ環境は、条件によって有償になる Docker Desktop ではなく Rancher Desktop を使います。
    GitHub Copilot だけは利用契約が必要です。組織から割り当てられたアカウントを使ってください。

## 所要時間

**全体で 1 週間** を目安にしています。
インストール作業そのものは初回 2〜3 時間で終わることが多いです。
残りの時間は、各章の「なぜ必要か」を読み、理解度チェックに答え、つまずいたら自分で調べる時間に使ってください。

## 前提

- PC: Windows 11（64 ビット）、メモリ 16GB 以上を推奨（コンテナに 4GB 以上を割り当てるため）
- 権限: ソフトのインストールに管理者権限が必要な場面があります。社用 PC で権限が無い場合は、事前に申請してください
- ネットワーク: 社内プロキシがある場合は、プロキシの設定値と社内 CA 証明書の入手方法を先に確認しておくと安心です

!!! note "macOS・Linux を使う場合"
    手順は Windows を中心に書いていますが、Git Bash 向けのコマンドは macOS・Linux のターミナルでもほぼそのまま動きます。
    Rancher Desktop・Corretto・VS Code にはそれぞれ macOS 版・Linux 版があります。
